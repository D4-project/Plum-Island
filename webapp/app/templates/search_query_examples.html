Combine filters

Match scans with port 443 and an HTTP server containing nginx.

Match either filter

Match scans with port 443 or port 22.

Group alternatives

Match nginx on port 443, or match port 22. Parentheses keep each group together.

Exclude matches

Match port 443, excluding scans whose HTTP server contains nginx.

Starts with

.bg / .begin: starts with nginx. Matches nginx/1.26, but not custom-nginx.

Contains

.lk / .like: contains nginx anywhere. Matches both nginx/1.26 and custom-nginx.

Search an HTTP header value

Match collected x-powered-by header values containing php, such as php/8.2. The modifier applies to the value.
